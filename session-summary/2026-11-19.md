## 3. Technical Learnings
- **mcp 2.x SDK:**
  - The class is `MCPServer`. `server.run("stdio")` starts it.
  - Sync tools run on a worker thread, so a module lock really does serialise calls.
  - A plain exception reaches the client only as "Error executing tool <name>", with its text dropped. Raise `ToolError` to show a message.
  - In-process test client: `async with Client(server) as c: r = await c.call_tool(name, args)`. Then `r.is_error` and `r.content[0].text` (the JSON).
  - Subprocess client: `Client(StdioServerParameters(command=..., args=[...], cwd=...))`.
- **Tool output size:** at `k=12`, one query across 3 sources is 35–45 KB, about 10k tokens. Claude Code warns at that size and truncates at 25k tokens by default. That's why the tool's default `k` is 5.
- **First-call cost:** a source with no cached vectors is embedded inside the first call (13m43s for all three from empty). Warm the cache by running the command line once after a harvest. The docstring says so.
- **`scripts/check_requirements.py`** flags a direct import of a package that's only a transitive dependency (it caught `anyio` in a test). Use stdlib `asyncio` instead.
- **`tests/test_brief.py`** goes red when the spec changes. Run `python scripts/make_brief.py --write` and commit `docs/BRIEF.md`.
- **`~/.claude.json` reads are denied** to this session. MCP registration belongs to `server` anyway.
- Scratch `/tmp/claude-1000/-home-opc-edmonton-open-data-landscape/4f8f6a43-c416-44bc-9a01-8db952db7659/scratchpad/m6pr4/` holds before/after outputs. None of it needs keeping.
