## 3. Technical Learnings
- **Embeddings are independent of the corpus; TF-IDF and schema are not.** A per-source neighbour list from embeddings equals the joint list filtered to that source. TF-IDF and schema IDF are fitted on the pool, so adding sources shifts Edmonton's lists.
- **Search vectors** (`data/processed/search/<source>/<date>/vectors.npy` + `hashes.json`) embed `search_text`, which is title + tags + description + column names. That's not the landscape's unit text, which has no column names.
  - `search.build_index(name, snap, None, include_hidden=False, embed=False)` loads them without loading the model.
- **A batch-16 embed of 2,935 texts took 9 min 20 s and peaked at 1.1 GB.**
- **Local master can lag origin.** At session start the newest handoff on disk was S16's, and S18's was only on origin. `git fetch` and read `origin/master:session-summary/...` first.
- **`git checkout -p` inside a chained Bash command opens an interactive prompt and hangs.** It was stopped with no hunk discarded. Never use it in a script.
- **Calgary's catalogue has no property-tax-rate, mill-rate or levy dataset**, only assessments: `4bsw-nn7w`, `4ur7-wsgc`, `p84b-7zbi`. It's a candidate "what's missing" example, not yet recorded in the repo.
- **`docs/BRIEF.md` must be regenerated** (`python scripts/make_brief.py --write`) whenever the spec, TODO or DECISIONS change. `tests/test_brief.py` fails otherwise.
