## 3. Technical Learnings
- **`scripts/make_brief.py` without `--write` only prints.** Run it with `--write`, or
  `test_committed_brief_is_current` fails.
- **What reaches `docs/BRIEF.md`:**
  - A `DECISIONS.md` row does. So PR #81 changed a synced file.
  - Nested TODO sub-items and `ASSUMPTIONS.md` rows don't. PR #82 left the brief unchanged.
- **`re.match` already anchors to the start of the line.** Removing `^` from a pattern used
  with `.match` is not a real break test; I tried it on `OWNER_RUNS` and it stayed green.
- **The spot-check labels favour the current methods.** All 210 pairs came from the current
  TF-IDF, schema and embed lists. Any new variant has to label the pairs it newly surfaces
  before its precision can be compared; "known-yes kept" alone reads as a false loss.
- **The probe's picks are dataset ids.** `probe_score` takes unit keys, so the future CLI must
  map ids to units with `units.csv` `member_ids`. A pick that is a member of the card's own
  series counts as a self pick.
- **`search_datasets` (MCP) serves the 2026-11-27 snapshot.** The probe and the labels use
  2026-10-02. The unit 3 candidates were checked against the 2026-10-02 `units.csv`.
