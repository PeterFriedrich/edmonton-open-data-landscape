## 3. Technical Learnings
- **The Socrata Discovery snapshot holds all public official assets:** dataset 1,426, map 280, chart 179, filter 109, story 61, href 21, file 18, calendar 1 (2,095 total), and 608 have a `parent_fxf`. Private parents (e.g. `2g3t-excm`) return "You must be logged in". Row counts aren't in the snapshot; get them live with `$select=count(*)`.
- **Calgary** is Socrata: `api.us.socrata.com/api/catalog/v1?domains=data.calgary.ca` gives 413 datasets. `src/harvest.py:32` hard-codes `DOMAIN`.
- **open.alberta.ca** is CKAN: `/api/3/action/package_search`, no key, 0.3 s per call.
  - 37,654 records: `type:opendata` 3,021, `publications` 34,614 (33k PDF).
  - AER holds 1,339 of the opendata records. There are no column schemas.
  - Already used per-package by `alberta-regional-viz` (`src/fetch_fir.py`, `src/fetch_equalized.py`) and `edmonton-nonprofit-map` (`src/download_alberta.py`). Nobody harvests the catalogue.
- **StatCan WDS:** `https://www150.statcan.gc.ca/t1/wds/rest/getAllCubesListLite` returns 8,283 tables (5 MB) in 3.5 s. `archived` "2" ≈ current (5,091); that's my reading of the codes. The full `getAllCubesList` adds dimension names.
- **Existing tools, none semantic for these portals:**
  - mcp-canada (ReyemTech, unofficial, MIT, 266 tools; Alberta search is CKAN keyword);
  - ondata/ckan-mcp-server (generic CKAN, keyword);
  - statcan-mcp (npm, keyword);
  - R `cansim` (title substring);
  - Eisenh/OpenAlberta (Svelte vector-search web app, 1 star, stale);
  - Firecrawl Alexandria (paid).
- **Agreed direction (in the spec):** one record format, one adapter per platform (Socrata, CKAN, later WDS), one index per source per snapshot, a CLI with `--source`/`--json`, then an MCP server that keeps the model loaded. Registering it for every session is `server`'s call.
- **Gotcha:** `src.inventory.build_inventory(raw)` returns non-string values, but `build_units` expects CSV strings. `src/search.py` stringifies, which builds the inventory in memory for snapshots without an inventory CSV. Only `data/processed/inventory/2026-10-02.csv` exists.
- **Gotcha:** `scripts/make_brief.py` without `--write` doesn't update `docs/BRIEF.md`; `tests/test_brief.py` fails until you run it with `--write`.
