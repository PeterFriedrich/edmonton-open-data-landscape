## 3. Technical Learnings
- **mcp 2.3.0 HTTP:**
  - Start it with `MCPServer.run("streamable-http", host=, port=, streamable_http_path=, stateless_http=)`. `streamable_http_app(**same)` returns a Starlette app to serve with uvicorn.
  - With host 127.0.0.1, localhost or ::1, the SDK turns on DNS-rebinding protection by itself.
  - Client: `Client("http://127.0.0.1:<port>/mcp")`.
- **Tests that talk over HTTP need `asyncio.wait_for`.** Without it, the "bind 0.0.0.0" mutation hung pytest until the tool timed out, and while it hung, the mutated file stayed on disk. Restore from a backup copy after any mutation run that gets killed.
- **Redeploys are manual.** After a merge that changes `src/mcp_server.py`, `src/search.py`, `src/records.py`, `src/inventory.py` or `src/similarity.py` (the server's transitive imports), message `server`. They check out `origin/master` in the worktree and restart the unit. The rule is recorded in the project `CLAUDE.md`.
- **The deploy worktree belongs to `server`.** A `git -C ~/edmonton-open-data-landscape-mcp ...` command was denied by the auto-mode classifier. Don't touch it; test in a scratch repo instead.
- **User journald isn't persistent on this box,** so `journalctl --user -u open-data-search` may show nothing.
- **The owner merges within minutes.** #61 merged during a 45 s test run, and the `gh pr view ... | grep -qx OPEN &&` chain before commit caught it.
